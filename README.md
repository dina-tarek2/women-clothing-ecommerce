# Women Clothing E-commerce

Full-stack e-commerce platform for women's clothing and hijabs,
with a guest browsing and checkout experience.


## Project Structure

- `frontend/` - Next.js application
- `backend/` - API (coming soon)


## Features (in progress)
- Browse products without an account (guest mode)
- Product filters by category, size, color and price
- Product variants (colors & sizes) with stock per variant
- Cart & wishlist saved locally for guests
- Guest checkout with order tracking by phone number
- Optional account for order history

## Tech Stack
- **Frontend:** Next.js (App Router), TypeScript, Tailwind CSS, Zustand, React Hook Form + Zod
- **Backend:** Coming soon

## Getting Started

```bash
cd frontend
npm install
npm run dev
```

Then open http://localhost:3000
